# Diptychon is free

Decided 2026-09-21 by Till, after the site went live on the new homepage.
Supersedes ADR 0007 (one-time purchase, no subscription).

## The decision

Diptychon is free. There is no price, no purchase, no subscription and no
account. The website says "free" wherever it describes Diptychon's price, and
no longer says "one-time purchase" or "price not set".

## What this does not decide

- **Open source.** Free is not the same as open source. The PRD still says
  "MIT license"; whether the code is published, and under which licence, stays
  open (issue 66 records the Copyleft-vs-MIT argument).
- **Forever.** The site says "free", not "free forever". No promise about the
  future is made on the page.

## Consequences

- ADR 0007 no longer holds. Its reasoning against subscriptions still stands:
  no recurring billing is also true of free.
- Issue 66 (open core vs one-time purchase) is closed by this decision.
- Competitor comparisons keep their competitor prices; only Diptychon's column
  changed. The "no subscription" angle against Path Finder still holds.
