# Creative Brief — Diptychon Mark & Wordmark

**Status:** draft for review · July 8, 2026
**Deliverable this brief steers:** an image-generation concept board (6–10 directions), from which 1–2 get vectorized.

## What the mark must express (in priority order)

1. **Two panels.** The diptych is the product. Two side-by-side vertical
   structures with a clear gutter between them — visible in under a second,
   at any size. Non-negotiable.
2. **The work, in motion.** The panels are not empty frames: they hold
   blocks (files, the user's material), and one block must read as
   *in transit* across the gutter. The send-across keystroke is the
   product's core moment — the transfer is part of the brand, not a bonus.
3. **Restraint.** Two flat tones from the app itself (#282828 ground,
   #D9D9D9 mark). No gradients, no gloss, no 3D, no mascot energy.
   Zed/Linear craft bar: quiet, precise, confident.

## Equity to keep from the current mark

The fragmented mosaic quality — panels built from broken blocks — and the
**secondary reading**: on second look the panel fragments resolve into "DT".
That double reading is the cleverness worth preserving: it is *preferred*,
and a concept that drops it must be very good to win on other merits.
A mark that is *only* letters (the failed restyle) or *only* panels loses
either the name or the product.

## Hard constraints

- Sits on Apple's 824 px icon grid inside the 1024 canvas; system squircle radius.
- Survives 16 px: either the mark itself simplifies gracefully, or the
  direction includes an explicit reduced variant for 16/32 px slots.
- Works against both light and dark Dock backgrounds.
- Flat vector-reproducible shapes only (final art is SVG/PDF, not a painting).

## Wordmark direction

The mark carries identity; the name carries clarity — do **not** illustrate
the name. "diptychon" set in a real typeface (the site's mono micro-label
motif is the natural home: `ui-monospace`, lowercase, letterspaced), with at
most one crafted detail (e.g. a modified glyph or a deliberate gap echoing
the gutter). No pixel-block lettering.

## Anti-goals (auto-reject)

Folder glyphs · arrows in circles · literal file/document icons ·
gradients or glass · blue-everything · pixel-art lettering ·
generic "two rectangles" with no work in them.

## Fitness tests for the concept board

| Test | Pass condition |
|---|---|
| Panel test | A stranger says "two panels/columns" within 1 s |
| Work test | The blocks inside read as content, not decoration |
| Transfer test | **Required** — one block reads as moving left→right |
| Squint test | At 16 px, still two structures with a gutter |
| Mono test | Works in exactly two flat tones |
| Dock test | Looks native next to Finder, Safari, Zed |
| DT test | Preferred — letters emerge on second look, never first; letter-free concepts must clearly win elsewhere |

## Concept territories for the board

- **A. Two leaves** — a literal diptych: two panels of stacked blocks, one
  block crossing the gutter mid-transfer.
- **B. Mosaic columns** — evolution of the current mark: two column
  structures assembled from work-blocks; DT as the emergent second reading.
- **C. The gutter** — the divider as hero: negative space splits a single
  block field into two panels; one block sits astride the line.
- **D. Punched card** — one dark slab, work-blocks punched out as light
  negative space forming two panel groups (most abstract, most Zed-like).
  *Stretch territory: only viable if one punched block sits astride the
  gutter and reads as crossing — static compositions fail the transfer test.*
