# Netnographie: File-Manager-Nutzer auf macOS

Social-Listening- / Netnographie-Studie zu Nutzer:innen von Dual-Panel-/Commander-
Dateimanagern (Marta, Total/Nimble Commander, ForkLift, Path Finder, QSpace u. a.)
und Finder-Umsteiger:innen. Ziel: **Kundenwünsche, Trends und Nutzerverhalten**
systematisch aus öffentlichen Community-Daten ableiten, um die Produktentscheidungen
für **Diptychon** empirisch zu unterfüttern.

Methodik folgt Kozinets' Netnographie (Planning & Entrée → Data Collection → Ethics →
Analysis & Presentation) und der von der Auftraggeber:in vorgegebenen Best-Practice-
Checkliste.
