Download sizes for Marta (10.7 MB), ForkLift (16.3 MB) and Path Finder (19.4 MB) via MacUpdate; Nimble Pro $29.99 and Marta free as of 2026-07-07. Diptychon's 2.7 MB is the zip of the current notarized build, measured 2026-08-10. Prices change. Check the vendor before you buy.

Undo & session, verified 2026-07-11: Marta has no file-operation undo (open request since 2018) but documented session restore; ForkLift's release notes show undo for Trash & Multi-Rename, full scope undocumented, restore via its "Restore Windows and Tabs on Startup" setting; Nimble Commander's manual documents no undo, session restore is on by default; Path Finder added an "undo panel" for moves, extent undocumented, and layout restore is a manual "Save As Default". Diptychon's undo is multi-level across move, copy, trash and rename; overwrites are destructive and excluded. Batch rename: documented for ForkLift (Multi-Rename), Nimble Commander (Batch Rename) and Path Finder (Batch Renaming); Marta's file-operations reference lists only single-item rename. Diptychon's batch rename covers Finder-style modes (replace, add text, format with counter, change case) as one undoable operation; regex patterns are planned.

Where each one wins (honestly)

Marta

Wins: free, keyboard-cult-favorite, native and plain-fast.

Diptychon's edge: undo-anything and real Finder tags.

ForkLift 4

Wins: the remote powerhouse (SFTP/FTP/WebDAV/S3/cloud/SMB), folder sync, multi-rename.

Diptychon's edge: built keyboard-first: every action has a binding, one chord moves files between panels, all in a 2.7 MB download.

Nimble Commander

Wins: raw C++ speed, 100+ hotkeys, remote mounts, open-source.

Diptychon's edge: gentler to learn (Nimble's curve is steep), undo, native Finder tags. No feature paywall, and free while in beta.

Path Finder

Wins: the deepest, kitchen-sink power-feature set, still actively maintained.

Diptychon's edge: free while in beta, and planned without a yearly subscription ($32.95/yr).

Diptychon is for you if…

  • You live in the keyboard and Finder feels slow.
  • You want native + tiny, not a web wrapper.
  • No subscription, no telemetry matters to you.
  • You mostly work on local (or mounted) drives.
