Looking for a Marta alternative?

Marta is free, native Swift, dual-pane and genuinely fast — for most people it is the right answer, and it costs nothing to try. People go looking for an alternative for two specific reasons, and neither is about speed.

The first is continuity: Marta is a one-person project and development has come in bursts, with long quiet stretches between releases. The second is undo: Marta has no undo for file operations — the request has been open since 2018. Its documentation describes delete as permanent. Batch rename is also absent; the file-operations reference lists single-item rename only.

Questions people actually ask

Is Marta still being maintained?

Yes, but in bursts. Marta is developed by a single developer, and its release history has long quiet stretches followed by a new version. That pattern is the single most common worry raised about it in Mac power-user communities — not capability, not speed. If a one-person project with irregular releases is a risk you are comfortable with, it is not a reason to leave.

Does Marta have undo?

No. There is no undo for file operations. The request has been open since 2018, and Marta's own documentation describes deletion as permanent. In practice this means a mis-aimed move or delete in a keyboard-driven tool is not recoverable from inside the app.

This is the single clearest functional gap between Marta and Diptychon. Diptychon's undo is multi-level across move, copy, trash and rename. Overwrites are the documented exception — they destroy the original and cannot be reversed, in any tool.

Does Marta have batch rename?

No. Marta's file-operations reference documents single-item rename (⇧F6) only. ForkLift, Nimble Commander and Path Finder all have a batch rename; Diptychon has one too, with Finder-style modes (replace, add text, format with a counter, change case) applied as a single undoable operation. Regex patterns are planned, not shipped.

What is the closest alternative to Marta?

By philosophy, Nimble Commander — native, keyboard-heavy, free, and open source, so continuity is not a single-developer bet. It is faster still (C++) and has 100+ hotkeys, but the learning curve is steeper and it has no undo either.

By feel, Diptychon is the closer match: same keyboard-first two-panel model, smaller (1.5 MB vs 10.7 MB), with undo and real Finder tags added. It costs money, has no plugin system, and has not launched.

Is Marta open source?

No. Marta is free but not open source — only its issue tracker is public on GitHub. Nimble Commander is the open-source option in this category.

Switch from Marta if…

  • You have lost files to a mis-aimed move and want undo.
  • You rename in batches.
  • You use Finder tags and want them round-trip.
  • Single-developer continuity worries you.

Stay on Marta if…

  • You use its plugins.
  • Free matters more than undo.
  • You need something today.
  • It already does what you need — it is good.
